    À RETENIR

    Un schéma décrit la table. Il ne contient pas les résultats.

    Pour remplir une base MySQL : exécutez la requête dans Wikidata Query Service, exportez le CSV, puis importez les données dans la table créée.

    Quelles transformations sont prises en charge ?

    L’outil extrait les colonnes d’un SELECT explicite, avec DISTINCT, REDUCED ou des expressions avec AS. Les commentaires, les préfixes et les chaînes de caractères sont pris en compte.

    Pour SELECT *, indiquez les variables à exporter. Le corps WHERE n’est pas traduit en SQL, aucune relation entre tables n’est inventée et la syntaxe SPARQL complète n’est pas validée. Testez toujours la requête dans Wikidata.

    Une image Wikidata est une URL, une coordonnée P625 est un texte WKT et une date historique peut dépasser les formats de MySQL. Choisissez vos types après avoir regardé les données.
